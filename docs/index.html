What does Alzheimer's leave in the spinal fluid?

A reanalysis of the cerebrospinal fluid proteome of 197 people (PRIDE PXD016278): a neuronal injury signature that tracks CSF tau.

Interactive viewer → Explore any protein by cohort: volcano plot with adjustable FDR, effects in each cohort, abundance by site and relation to CSF tau. Runs in the browser; the first load takes a few seconds. Analysis report → Missing-value methods, differential abundance, sensitivity analyses, diagnostic classifier and circularity of the diagnostic label. QC report → Sample quality control: batch offsets, missing values, blood contamination, plasma content and global structure.
Code, methods and reproduction: GitHub repository · Data: Bader et al., Mol Syst Biol 2020
